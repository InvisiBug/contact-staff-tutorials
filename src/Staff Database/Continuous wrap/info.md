A reasonably simple move developed from an elbow wrap. just do an elbow wrap but catch the staff with the same hand. I would have put this in the crap tricks section, if it wasn't so darned hard to do, and if once in a while I didn't get the feeling it could be developed into continuous elbow throws like baton twirlers do. Can be done to front side and back - both hands.
